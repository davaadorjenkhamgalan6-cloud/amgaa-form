# Үзлэгийн хүсэлтийн форм

## Ажиллагаа
1. Үзлэг хүссэн байгууллагын менежер формыг бөглөж, өөрийн нэр, имэйлийг бичээд илгээнэ.
2. Захирал болон хянагчид **Зөвшөөрөх / Татгалзах** товчтой имэйл очно.
3. Аль нэг нь шийдвэр гаргахад хангалттай:
   - **Зөвшөөрөх** дарвал менежерт «зөвшөөрөгдлөө» гэсэн имэйл очно.
   - **Татгалзах** дарвал шалтгаанаа бичиж, менежерт шалтгаантай имэйл очно.
   - Нөгөө хянагчид шийдвэрийн тухай мэдэгдэл очно.
4. Бүх хүсэлт, төлөв нь «Үзлэгийн хүсэлтүүд» Google Sheet-д хадгалагдана. Supabase-ийн `requests` хүснэгтэд нөөц хуулбар нь хадгалагдана.

## Apps Script суулгах (нэг удаа)
1. https://script.google.com дээр **New project** үүсгэнэ.
2. `apps-script/Code.gs`-ийн агуулгыг бүхэлд нь хуулж, `Code.gs` руу буулгана.
3. Дээд хэсгийн `CONFIG` дотор захирлын болон өөрийн **нэр, имэйлийг** бичнэ.
4. Дээрх цэснээс `setup` функцийг сонгоод **Run** дарна. Эрх асуухад **Allow** дарна.
5. **Deploy → New deployment → Web app**-ийг сонгоод:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
   - **Deploy** дараад гарах `.../exec` холбоосыг хуулна.
6. Энэ холбоосыг `index.html` дахь `APPS_SCRIPT_URL = ""` гэсэн хэсэгт тавина.

`Code.gs`-ийг өөрчилсөн бол **Deploy → Manage deployments → Edit → New version** гэж шинэчилнэ.

## AMGAA ERA-тай холбох (ирсэн хүсэлтийг үзлэгийн бүртгэлд оруулах)
1. Apps Script дээр шинэ `Code.gs`-ийг буулгаад **Deploy → Manage deployments → Edit → New version** гэж шинэчилнэ (холбоос өөрчлөгдөхгүй).
2. Цэснээс `showListKey` функцийг сонгоод **Run** дарна. **Execution log**-д гарах `AMGAA ERA-ийн түлхүүр: ...` утгыг хуулна.
3. AMGAA ERA → **Үзлэгийн бүртгэл → 📥 Ирсэн хүсэлт** таб дээр түлхүүрийг буулгаад **Холбох** дарна.

Үүнээс хойш зөвшөөрөгдсөн хүсэлт бүр «Бүх үзлэг» жагсаалтад шинэ үзлэг болж автоматаар орно (объект, хаяг, хүссэн огноо, тайлбар нь бөглөгдсөн байна). Хүлээгдэж буй хүсэлтийг **Үзлэгт оруулах** товчоор гараар оруулж болно. Түлхүүргүйгээр хүсэлтүүдийн жагсаалтыг хэн ч харах боломжгүй.
